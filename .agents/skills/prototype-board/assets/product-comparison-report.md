# [기능] 제작 후 확인 보고

공통 기획의 해시를 추적할 때 사용하는 별도 보고서다. 제작 전에 확정한 기획 원본을 수정하지 않고, 이 문서에서 원본과 결과물을 참조한다. 단일 화면이며 해시 추적이 필요 없다면 별도 문서를 강제하지 않는다.

## 사용한 기획 원본

| 공통 기획 ID | 버전 | 확정한 원본 파일명 | 원본 파일의 SHA-256 |
| --- | --- | --- | --- |
| | | | |

원본의 정확한 바이트로 해시를 계산한다. 공통 기획 파일에 자기 해시를 다시 쓰지 않는다. 원본을 바꾸면 새 버전으로 제작하고, 기존 버전으로 남는 결과물을 명시한다.

## 최종 전달 목록

제작 중간 파일을 제외한 최종 파일만 기록한다. 각 파일은 생성 시점의 공통 기획 복사본이며 서로의 시연 상태와 자동 동기화되지 않는다. 새로 제작하지 않은 관점은 이전 버전으로 표시한다.

| 관점 | 최종 파일명 | 공통 기획 버전 | 크기 / HTML 파일의 SHA-256 | 보드·첨부 식별자 / 다운로드 일치 확인 |
| --- | --- | --- | --- | --- |
| | | | | |

공통 파일 해시와 HTML 파일 해시는 별도로 계산한다. 아직 받지 않은 등록 식별자를 만들지 않는다. 최종 목록을 `source` 결과물로 저장할 때는 그 목록 자체의 해시나 등록 후 받은 식별자를 같은 목록에 다시 넣지 않는다. 목록의 등록 결과는 별도 작업 기록으로 보관한다. 공유할 때는 수신자가 접근할 수 있는 첨부 파일명이나 확인한 공유 링크를 안내한다.
